# PRESSPLAY MATCHDAY

Standalone offline-first field hockey live substitution manager.

## Stack

- React
- TypeScript
- Vite

## Local launch

From the project root:

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local URL shown by Vite in the browser.

## Phase 1 included

- Dark matchday interface
- squad setup with custom groups
- four 15-minute quarters
- substitution grid model
- planned vs actual toggle
- current quarter and live clock
- next substitution queue
- player control panel
- local state persistence in browser storage
- undo last action

## Notes

This project is intentionally kept at Phase 1 only, following the requested stop point before advanced tactical intelligence, injury recalculation, or PC-unit protection.
